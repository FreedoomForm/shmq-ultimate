v85 deep research proposed compile-time precision specialization to eliminate hot-loop runtime branches. Source inspection proved that the current monolithic kernel derives each CTA precision from blockIdx.x because one grid spans INT4, INT8, and FP16 channel tiles. A compile-time template parameter cannot vary per CTA inside one launched grid. Safe options are either three separate kernel launches with specialized grids, which violates the monolithic one-kernel requirement and changes launch orchestration, or a complete duplicated template-body refactor with a runtime wrapper and new output/partition plumbing. A local branch replacement would not actually remove the runtime dispatch and risks precision contamination. No source change and no Kaggle measurement were made; clean v51 remains active.
